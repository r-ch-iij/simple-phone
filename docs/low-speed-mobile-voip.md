# 低速モバイル回線での WireGuard VPN と VoIP 通話の可否

## この文書の目的
この文書は、Povo の低速回線（最大 128kbps）と IIJmio の低速モード（最大 300kbps、バースト転送つき）で、WireGuard VPN 経由の VoIP 通話が成立するかを調査した結果をまとめたものです。
KYF42 の SIP 内線を外出先から使う場合に、低速回線でも実用になるかを判断する材料として参照します。
調査時点（2026-08）の情報であり、料金プランや速度制限の仕様は変更される可能性があります。

## 各回線の仕様
**Povo 2.0** は、データトッピングの残量がなくなると通信速度が最大 128kbps に制限されます。
この制限は au 回線の速度制限であり、ユーザー側で低速に切り替える機能はありません。
**IIJmio の低速モード** は、ユーザーが高速データ通信をオフにすることで切り替えます。
低速モード中の通信はデータ容量（ギガ）を消費しませんが、通信速度は最大 300kbps に制限されます。
**IIJmio のバースト転送** は、低速モード中に通信を開始した際、最初の一定量を高速で転送する機能です。
IIJ の 2014 年の資料によれば、「200kbps × 3 秒分 = 75KB 相当」を通信開始時に高速転送します。
低速モードで直近 3 日間の通信量が 366MB を超えると、さらに 128〜200kbps に制限され、バースト転送も使えなくなります。
制限は、直近 3 日間の通信量が 366MB 未満になった翌日に解除されます。

## 速度制限はプロトコルを問わない

いずれの制限も、TCP と UDP を区別しないレート制限です。
そのため、WireGuard が使う UDP がブロックされることはありません。
WireGuard のトンネル確立（ハンドシェイクは数 KB）や、SIP のレジストレーション、DTMF（RFC4733 は数字 1 回あたり数十バイト）は、128kbps でも余裕で成立します。
疎通の意味（トンネルが張れて SIP 登録が維持できる）であれば、どちらの回線でも問題ありません。

## 音声通話に必要な帯域
音声は双方向に流れるため、上りと下りでそれぞれ帯域が必要です。
WireGuard のオーバーヘッドは 1 パケットあたり約 60B（IPv4）です。
RTP のヘッダとあわせた、コーデック別の実帯域は次のとおりです。

| コーデック | 20ms パケット化 | 30ms パケット化 | 40ms パケット化 |
|-----------|----------------|----------------|----------------|
| G.711 (ulaw/alaw) | 約104kbps | 約91kbps | 約84kbps |
| GSM 13kbps | 約53kbps | 約48kbps | 約45kbps |
| iLBC 13.33kbps | 約53kbps | 約48kbps | 約45kbps |
| G.729 8kbps | 約48kbps | 約44kbps | 約42kbps |

G.729 はライセンスの問題があるため、実運用では選びにくいです。

## 回線ごとの判定
**IIJmio の低速モード（最大 300kbps）** では、G.711 でも必要帯域の約 3 倍の余裕があり、実用可能です。
ただし、3 日間 366MB を超えた後の制限状態（128〜200kbps）では、Povo と同等かそれ以上に厳しくなります。
**Povo の 128kbps 制限** では、G.711 は実効速度が 100kbps 前後に落ちることが多いため、帯域がほぼ飽和し、途切れや遅延のリスクが高くなります。
パケット化を 30〜40ms に延ばして約 84〜91kbps に抑え、ジッタバッファを拡大すれば、何とか会話できるレベルになります。
GSM または iLBC を使えれば、128kbps でも十分な余裕があります。

## 低速回線特有のリスク
UDP には再送がないため、パケットロスはそのまま音声の欠落になります。
速度制限中の通信は、輻輳時に優先度が低く扱われることがあり、遅延ジッタや数百 ms 級のバッファリング遅延が発生します。
ジッタバッファの容量を超えると音声が途切れます。
帯域適応型の LINE 通話でさえ、128kbps では「話せるが少し途切れる」という実測報告が一般的です。
G.711 は LINE 通話より帯域を消費するため、品質はさらに下がります。

## 実用に向けた推奨
IIJmio の低速モードで使う場合は、G.711 のままで実用できます。
3 日制限を避けるため、低速モード中の通信量は 3 日で 366MB 未満に抑えます。
G.711 の音声通話は 1 時間あたり約 45MB、iLBC は約 20MB です。
Povo の 128kbps 制限で使う場合は、GSM または iLBC を PBX と端末の両方で有効にします。
PBX 側の例として `allow=ulaw,alaw,ilbc` がありますが、端末側（KYF42 純正アプリ等）の対応は機種・アプリ依存です。
どちらの回線でも、WireGuard の `PersistentKeepalive=25` と、PBX 側のパケット化を長めに提示する設定を入れておきます。
